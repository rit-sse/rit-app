## Tech Stack

This repository is split into a mobile app in `app/` and an API server in `webserver/`.

| Area | Technologies |
| --- | --- |
| Mobile app | Expo, React Native, React 19, TypeScript |
| Navigation and UI | Expo Router, React Navigation, NativeWind, Tailwind CSS |
| Platform support | iOS, Android, and web via Expo |
| Backend API | Node.js, Express, TypeScript |
| Data layer | Prisma ORM, PostgreSQL |
| Supporting libraries | Mapbox, React Native Maps, Expo Notifications, Cheerio |
