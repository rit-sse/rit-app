Widget Labs — Society of Software Engineers (SSE) Tech Committee
===============================================================

Welcome to Widget Labs — a collaborative space where members of the Society of Software Engineers Tech Committee can design, build, and share small, reusable widgets for the RIT app.

Purpose
- Provide a lightweight "sandbox area" for creating features.
- Encourage experimentation, peer review, and rapid iteration on useful app extensions.

Who should contribute
- SSE Tech Committee members.

How to contribute
1. Fork or branch from the main repo and create your widget inside `app/widgetlab/<your-widget-name>`.
2. Include a short `README.md` for your widget describing purpose, props, and any required permissions or API keys.

Tech & guidelines
- Follow the app's existing stack and style (TypeScript, React/React Native, Tailwind where used).
- Prioritize accessibility (labels, roles, color contrast) and performance.
